# GYMMANAGE

FitCore GMS — a web-based gym management system for local fitness centers.

## Features

- Member management (register, profiles, membership status)
- Billing & payments with expiry calculation and digital receipts
- Trainer scheduling with automatic conflict detection
- Walk-in management
- Renewal reminders for expiring memberships
- Reports & CSV export
- Admin, staff, and trainer user roles

## Tech

Plain HTML, CSS, and JavaScript (single-page app, data stored in localStorage).

## Run

Open `index.html` in a browser.
